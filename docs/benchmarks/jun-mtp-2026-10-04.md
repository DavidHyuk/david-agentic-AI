matched OFF/ON run 최소 available은 35.56/30.08GiB, free는 16.94/11.44GiB로
available 차이는 약 5.48GiB였습니다. 최대 GPU 86/85°C, 최소 relative margin
−3°C이며 양쪽 software thermal slowdown이 관측됐습니다. hardware thermal
slowdown과 sampling 오류는 없었습니다. 별도 production control은 다른 build,
cache/guard와 약 2시간 간격이 있어 feature 비교나 cache 절약량 근거로 쓰지 않습니다.

native **28.53 TPS**였습니다. 입력은 첫 20,551, 후속 처리 1,286 / 캐시 19,606입니다.
