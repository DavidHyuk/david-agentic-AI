이 실험에는 Langfuse 권장

Hermes·llama.cpp·vLLM에서 얻는 지표를 OpenTelemetry 실험으로 묶을 수 있고, 스트리밍 TTFT를 직접 기록할 수 있습니다. 로컬 운영 선택지도 있습니다.

외부 프로젝트 키가 없어 현재 결과는 로컬에 저장했습니다. 준비된 전송 명령은 측정이 끝난 뒤 숫자·해시만 보냅니다.

실험 지원 · 자체 호스팅

LangSmith는 LangGraph 평가의 선택지

ClawGram에는 선택적 exporter 코드가 이미 있습니다. LangGraph 흐름과 데이터셋 기반 품질 평가에 적합하고 TTFT도 지원합니다. 새 중앙 실험 기록에는 Langfuse를 추천합니다.

이번 화면의 서버 로그는 API TTFT와 전달 시간을 측정하지 않았습니다. 예전 실험의 절대 시각도 없으므로 전송 시 원래 요청 시각을 만들어 넣지 않습니다.
